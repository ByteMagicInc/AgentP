# Contributing to AgentP

Thanks for your interest in improving AgentP! Bug reports, suggestions, and pull requests are welcome. For substantial changes, please open an issue first so we can discuss the approach.

You confirm that you own those rights or are authorized to make this assignment on the copyright owner’s behalf. Identify any third-party material and its license; this assignment does not cover rights you do not own.

Submitting a pull request does not obligate ByteMagic Inc. to accept, merge, release, or maintain your contribution. AgentP remains distributed under GPL-3.0-only.

## Before submitting

- Follow the repository’s conventions in [AGENTS.md](AGENTS.md).
- Keep changes focused and include tests where appropriate.
- Run formatting, linting, and tests as described in the [README](README.md#building-from-source).
